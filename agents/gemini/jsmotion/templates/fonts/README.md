# Fontes do template editorial

| Arquivo | Fonte | Uso | Licença |
|---|---|---|---|
| `serif.woff2`, `serif-italic.woff2` | [Playfair Display](https://fonts.google.com/specimen/Playfair+Display) (variável) | títulos, destaque em itálico dourado | SIL OFL 1.1 ([OFL-Playfair.txt](OFL-Playfair.txt)) |
| `sans.woff2` | [Inter](https://fonts.google.com/specimen/Inter) (variável) | números, dados, legendas, botões | SIL OFL 1.1 ([OFL-Inter.txt](OFL-Inter.txt)) |

Reduzidas ao alfabeto latino (português, espanhol, inglês) com `pyftsubset --flavor=woff2`.
Para outra fonte: baixe de github.com/google/fonts, reduza e aponte em `config.json` → `"fonts"`.
